## Reference log

- 2026-11-24: Phase 0 — quarantine performed. No references consulted.
- 2026-11-24: Phase 1 — base-R fixtures generated (R 4.3.3 from Ubuntu packages). WGCNA and
  HellCor were not installable in the build environment (CRAN/Bioconductor unreachable); their
  fixture sections are skipped and recorded in MANIFEST.json. No package sources were opened.
- 2026-11-25: Phase 3/8 — special functions written from DLMF §5.11, §8.7, §8.9, §8.17 and the
  published Lanczos (g = 7, n = 9) coefficients. No library source consulted.
- 2026-11-25: Phase 6 — Kendall from Knight (1966) and Kendall's tie-corrected variance formula.
- 2026-11-25: Phase 7 — bicor from the definition in Wilcox (2012) / Langfelder & Horvath (2012)
  and the WGCNA `bicor` documentation for `maxPOutliers` / `pearsonFallback`. WGCNA source not
  consulted; maxPOutliers parity unverified (no WGCNA fixtures).
- 2026-11-25: Phase 9 — hellcor from arXiv:1810.10276v4 (HTML version, fetched from arxiv.org
  via a search restricted to arxiv.org). The paper's CV criterion (App. C) differs from the
  rewrite specification's description; both implemented, paper's is default. No HellCor code
  seen. No search result displayed GPL source code at any point.
- 2026-11-26: Fixtures regenerated on the owner's Mac (conda env `r462`: R 4.6.2,
  WGCNA 1.74 and HellCor 1.3 installed from CRAN/Bioconductor), used strictly as
  black boxes. Incident: the package-installation log echoed compiler warnings that
  quoted one error-message line from WGCNA's C sources (a `pthread_join` failure
  message); it contains no algorithmic content and no WGCNA source file was opened.
  Later log checks used patterns that match only R's installer status lines.
- 2026-11-26: bicor `maxPOutliers` scaling (factor 2 on the quantile distance) and the
  hellcor default criterion (normalised leave-one-out) were chosen by comparing outputs
  of candidate implementations with the WGCNA/HellCor fixtures; no source consulted.
